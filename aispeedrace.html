⚠️ Important Limitations
🧠 Reasoning Models vs ⚡ Standard Models: Reasoning models (o1, o3, Gemini 2.5 Pro, DeepSeek R1) use "thinking tokens" between <think> and </think> tags before generating answers. They allocate variable compute based on problem complexity - spending 30-60 minutes on hard problems but seconds on simple ones. This makes direct speed comparisons fundamentally flawed.
Thinking Step Variability: The number of reasoning steps depends on problem complexity, computational budget, and training. DeepSeek R1-0528 averages 23,000 thinking tokens per complex problem (up from 12,000 in previous versions), while simple questions may use <1,000. Models can "give up" on extremely difficult problems despite having token budget remaining.
Source: ArXiv paper "DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning" (2025)
Cost Disparities: OpenAI o1 costs $2,767 across seven benchmark suites vs GPT-4o's $108 (25x more expensive). o3-pro charges $20 input/$80 output per million tokens. o1 generates 44 million tokens during benchmarking (8x more than GPT-4o).
Source: Artificial Analysis benchmarking study (2025)
Performance Regime Differences: Research shows three distinct regimes: (1) Low-complexity tasks where standard models outperform reasoning models, (2) Medium-complexity where reasoning models excel, and (3) High-complexity where both experience complete failure. Choose based on your use case complexity.
Source: Apple Machine Learning Research - "The Illusion of Thinking" (2024)
Prompt Sensitivity: o1-preview shows 30% accuracy drop on Putnam-AXIOM variations (functional problem variations), and 25-29% drops with gaslighting prompts. Chain-of-thought prompting causes 36.3% performance degradation on simple tasks due to excessive reasoning.
Source: Putnam-AXIOM Benchmark study (2024), Gaslighting Vulnerability Research (2024)
Thinking Token Cost Assumptions: This tool estimates thinking token usage for reasoning models based on research: OpenAI o1/o3 models (8x output tokens), DeepSeek R1 (12x output tokens, minimum 5k), Gemini 2.5 Pro (6x output tokens). These are conservative estimates - actual usage varies dramatically by prompt complexity. Simple questions may use <1k thinking tokens, while complex problems can use 50k+ tokens.
Note: Thinking tokens are billed as input tokens and significantly impact total costs for reasoning models.
Technical Implementation: This demo uses GPT-4's cl100k_base tokenizer via js-tiktoken for token counting, but actual models use different tokenizers (Claude's custom tokenizer, Gemini's SentencePiece, etc.) that split text differently. Speed simulation is token-based but approximate. Server load, prompt complexity, and response length create 10x+ variance from these averages.
Source: OpenAI API documentation, Anthropic documentation
