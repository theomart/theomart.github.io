# Theo Martin's Website

Personal blog and portfolio site built with Jekyll.

## Local Development

To render the website locally:

1. **Install dependencies**:
   ```bash
   bundle install
   ```

2. **Run the site**:
   ```bash
   bundle exec jekyll serve
   ```

3. **View the site**: Open http://localhost:4000

That's it! The site auto-refreshes when you save changes (except `_config.yml` which requires a restart).

## Deployment

Automatic deployment to GitHub Pages on push to gh-pages branch.
